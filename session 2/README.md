# Python Fundamentals – Core Concepts & Libraries

## Project Description

This project is a collection of Python practice exercises focused on learning and applying fundamental programming concepts. It explores Python lists, object-oriented programming, built-in functions, mathematical operations, user input, and basic data visualization using Matplotlib.

## Topics Covered

- **Lists:** Creating lists, accessing elements, and working with list length.
- **Object-Oriented Programming (OOP):** Creating classes and objects, defining constructors, and working with object attributes and methods.
- **Built-in Functions:** Using `min()`, `max()`, and `len()` to perform basic operations.
- **Math Module:** Performing mathematical calculations using Python's built-in `math` library.
- **Data Visualization:** Creating basic line plots and point plots using Matplotlib.
- **User Input:** Collecting and displaying user input using `input()` and `print()`.
- **File Handling:** Basic practice with opening and reading text files.

## Technologies & Libraries

- Python
- Math
- Matplotlib
- Jupyter Notebook

## Learning Objectives

The main objective of this project is to build a strong foundation in Python programming by practicing essential concepts, understanding object-oriented programming, exploring built-in modules, and creating basic visualizations.
