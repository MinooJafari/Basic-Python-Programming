# Text Typing Automation

## Project Overview
This project is a simple desktop automation program developed using Python and the PyAutoGUI library in Jupyter Notebook.

It automatically types a predefined German romantic message and presses the Enter key. The program uses keyboard automation to simulate human typing.

## Technologies Used
- Python
- Jupyter Notebook
- PyAutoGUI
- Time Module

## How It Works
1. Imports the PyAutoGUI and Time modules.
2. Waits for 3 seconds before starting.
3. Uses a `for` loop to repeat the typing process twice.
4. Automatically types a predefined German message.
5. Presses the Enter key after each message.

## Key Concepts
- Desktop Automation
- Keyboard Automation
- For Loops
- Time Delays
- Text Input Automation

## Installation

Install PyAutoGUI:

```bash
pip install pyautogui
```

## How to Run
Open the Jupyter Notebook file (`.ipynb`) and run the code cells.

Make sure the desired text input field is active before the automation starts.

## Purpose
The purpose of this project is to practice Python programming and explore desktop automation and keyboard interactions using PyAutoGUI.
