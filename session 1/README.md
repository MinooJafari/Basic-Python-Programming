# Digit Counter 

Project Description:

This project focuses on basic number analysis using Python. It includes functions for counting specific digits, checking divisibility, and identifying numbers within a given range.

## Features

- **Digit Counting:** Counts how many times digit 5 appears in a number.
- **Divisibility Check:** Checks whether a number is divisible by 5 using the modulo operator.
- **Range Analysis:** Counts how many numbers are divisible by 5 within a specified range.
- **Conditional Statements:** Uses if-else statements to identify a specific number.

## Technologies Used

- Python
- String Conversion
- Loops
- Conditional Statements
- Functions
- Modulo Operator (%)

## Learning Objectives

The purpose of this project is to practice fundamental Python programming concepts, including functions, loops, conditional statements, string manipulation, and arithmetic operations.
