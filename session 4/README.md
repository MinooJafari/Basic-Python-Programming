# Rock Paper Scissors 🎮

## 📌 About the Project

This project is a simple Rock Paper Scissors game developed using Python in Jupyter Notebook. The player competes against the computer, which randomly selects one of three options: Rock, Paper, or Scissors.

The game tracks both the player's and the computer's scores. The first player to reach 3 points wins the game.

## 🚀 Features

- Play against the computer.
- Random computer choices using Python's `random` module.
- Automatic score tracking.
- First-to-3-points winning system.
- Option to exit the game.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Random Module

## 🎯 How to Play

1. Open the Jupyter Notebook file.
2. Run the notebook cells.
3. Enter one of the following choices:
   - `sang` (Rock)
   - `kaqaz` (Paper)
   - `qeychi` (Scissors)
4. The computer randomly selects its choice.
5. The winner of each round earns one point.
6. The first player to reach 3 points wins.
7. Enter `0` to exit the game.

## 💻 How to Run

1. Install Python and Jupyter Notebook.
2. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

3. Open the project folder.
4. Launch Jupyter Notebook:

```bash
jupyter notebook
```

5. Open the `.ipynb` file and run the cells.
