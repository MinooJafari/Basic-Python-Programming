# Rock Paper Scissors 🎮

## 📌 About the Project

This project is a simple Rock Paper Scissors game developed using Python. The player competes against the computer, which randomly selects one of three options: Rock, Paper, or Scissors.

The game keeps track of the player's and computer's scores. The first player to reach 3 points wins the game.

## 🚀 Features

- Play against the computer.
- Random computer choices using Python's `random` module.
- Automatic score tracking.
- First-to-3-points winning system.
- Option to exit the game.

## 🛠️ Technologies Used

- Python
- Random Module
- While Loops
- Conditional Statements (if)
- User Input (`input()`)

## 🎯 How to Play

1. Run the Python program.
2. Enter one of the following choices:
   - `sang` (Rock)
   - `kaqaz` (Paper)
   - `qeychi` (Scissors)
3. The computer randomly selects its choice.
4. The winner of each round earns one point.
5. The first player to reach 3 points wins.
6. Enter `0` to exit the game.

## 💻 How to Run

Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd Rock-Paper-Scissors
```

Run the Python file:

```bash
python main.py
```
